## deploy.bat / deploy-ssh.bat 智能修复
- 用户双击 deploy.bat 报错：`'git' 不是内部或外部命令`。根因为本机 git 位于 WorkBuddy 便携路径 `%USERPROFILE%\.workbuddy\vendor\PortableGit\mingw64\bin\git.exe`，未加入系统 PATH，CMD 找不到。
- 修复：重写两个 bat，开头自动检测常见 git 路径（含 WorkBuddy 便携 Git），并把所在目录临时加入 PATH；自动检测 `.git` 是否存在，不存在则 `git init` + 添加 remote；自动 `git add -A` + 提交改动 + `git branch -M main` + `git push -f origin main`。
- 注意：脚本使用 force push，会覆盖远程 main 分支历史；`.gitignore` 已忽略 `.env` / `dist`，不会误传敏感文件或构建产物。
- 用户只需双击 `deploy.bat`，首次会弹 GitHub 登录/授权窗口；推送后 GitHub Actions 自动用已配好的 Secrets 构建部署。
- 二次修复：用户运行后发现 bat 中文被 CMD 按 GBK 解析成乱码命令（如 `'line'`、`'ite'`）。将两个 bat 全部改为纯英文提示，并确认文件无 BOM、前3字节为 `@ec`，彻底消除编码解析问题。若系统仍找不到 git，脚本会提示安装 Git for Windows 并给出下载链接。
